# 고신교회 디자인 가이드

모든 색상·글꼴·크기 값은 `assets/css/tokens.css` 의 변수에 있습니다. 그 파일의 값만 바꾸면 사이트 전체에 반영됩니다.

## 1. 방향
- **분위기**: 따뜻하고 신뢰감 있게. 화려한 효과보다 가독성과 편의성을 우선합니다.
- **기본색**: 교회 로고 방패의 **버건디(`#801237`)**. 보조색으로 따뜻한 베이지와 골드를 씁니다.
- **대상**: 고령 성도부터 청소년까지. 글자는 크게, 버튼은 누르기 쉽게.
- **모바일 우선**: 스마트폰으로 예배 시간과 위치를 찾는 경우가 많아서, 모바일 하단에 `전화하기 / 길찾기 / 예배시간` 고정 버튼을 둡니다.

## 2. 색상

| 변수 | 값 | 용도 |
|---|---|---|
| `--c-primary` | `#801237` | 기본색 (버튼, 링크, 강조). **로고 방패 색.** 흰 글자와 대비 약 10:1 |
| `--c-primary-dark` | `#5f0d28` | 버튼 눌림, 진한 강조 |
| `--c-primary-deep` | `#3d0d1f` | 제목, 가장 어두운 배경(히어로·배너 그라데이션 끝) |
| `--c-primary-soft` | `#f7e9ee` | 연한 버건디(분홍) 배경, 배지 |
| `--c-beige` | `#f7f0e4` | 보조색: 저서 구역, 인용 상자 |
| `--c-gold` | `#b8893b` | 장식선, 키보드 포커스 표시 (글자색 사용 금지, 대비 부족) |
| `--c-gold-text` | `#8a6320` | 글자로 쓰는 골드 (흰 배경 대비 약 5.4:1) |
| `--c-gold-light` | `#f3dcab` | 어두운 배경 위의 골드 글자 |
| `--c-ink` | `#2a1d22` | 본문 글자 |
| `--c-ink-soft` | `#5a4a50` | 보조 글자 |
| `--c-muted` | `#75666b` | 날짜, 보조 안내 (흰 배경 대비 약 5.4:1) |
| `--c-bg-soft` | `#f8f4f3` | 연한 따뜻한 회색 배경 |

그라데이션과 푸터 배경처럼 `style.css` 안에 직접 적힌 색은 위 토큰을 어둡게·밝게 조절한 값입니다. (`#6a0f2e`, `#b03a62`, `#2a0a16`, `#f3dde4` 등) 전체 색을 다시 바꾸려면 `tokens.css` 와 함께 `style.css` 의 그라데이션 색도 확인하세요.

배경은 흰색과 아주 연한 따뜻한 회색 위주로, 보조색(베이지)은 한 구역(저서)에만 써서 포인트를 줍니다. 카카오톡 버튼의 노란색(`#fee500`)은 카카오 브랜드 색이라 예외입니다.

> 색을 바꿀 때는 흰 글자와의 대비가 4.5:1 이상인지 반드시 확인하세요.

## 3. 로고
- 파일: `assets/img/logo.png` — 가로형(방패 + 대한예수교장로회 + 고신교회), 투명 배경 PNG(663×113).
- 헤더: 흰 배경 위에 그대로 사용 (PC 46px, 메뉴가 좁아지는 1279px 이하 38px, 모바일 34px 높이).
- 푸터: 어두운 배경이라 **흰색 판**을 깔고 그 위에 올립니다. (검은 글자가 어두운 배경에 묻히지 않도록)
- 파비콘 `favicon.png`: 로고에서 방패만 잘라 만든 128×128. 카카오톡·SNS 미리보기 `og-image.png`: 1200×630, 흰 배경 + 로고 + 하단 버건디 띠.
- 로고를 교체할 때는 같은 이름으로 덮어쓰거나 `data/church.js` 의 `logo:` 경로를 바꿉니다. 가로 비율이 크게 달라지면 `style.css` 의 `.brand-logo` 높이를 함께 확인하세요.

## 4. 글꼴
- 본문·UI: **Noto Sans KR** (400 / 500 / 700) — Google Fonts. 없을 때는 맑은 고딕 등 시스템 글꼴로 대체됩니다.
- 표어·큰 제목: **Noto Serif KR** (600 / 700) — 히어로 표어, 섹션 제목, 서브페이지 제목에만 사용.
- 본문 크기 **17px**, 줄간격 1.75. 한글이 단어 중간에서 끊기지 않도록 `word-break: keep-all` 적용.
- 글꼴을 Pretendard로 바꾸려면 각 페이지 `<head>` 의 Google Fonts 링크를 바꾸고 `--f-sans` 변수를 수정합니다.

## 5. 레이아웃과 간격
- 최대 폭 1180px, 좌우 여백 20px.
- 섹션 위아래 여백 72px (태블릿 이하 56px).
- 모서리 둥글기 14px(카드), 버튼은 완전한 알약 모양.
- 그림자: 가벼운 `--shadow-1`, 떠 있는 카드 `--shadow-2` (어두운 버건디 계열 반투명).
- 헤더: 로고(왼쪽) · 메뉴 6개 · 검색. 가로형 로고가 길어서 **PC 헤더에는 전화번호를 넣지 않습니다.** (전화는 모바일 하단 버튼, 푸터, 오시는 길, 문의 페이지에 있음)

## 7. 반응형 기준

| 폭 | 변화 |
|---|---|
| 1280px 이하 | 로고 38px, 메뉴 여백을 줄여 한 줄 유지 |
| 1024px 이하 | 상단 메뉴가 햄버거(전체 화면 메뉴)로 바뀜 |
| 960px 이하 | 2단 구성이 1단으로 |
| 768px 이하 | 하단 고정 버튼 3개 표시 |
| 760px 이하 | 예배 시간 카드 1열 가로형, 갤러리 2열 |
| 640px 이하 | 표가 카드형으로 |
| 480px 이하 | 로고 34px |

## 8. 접근성 규칙
- 글자와 배경 대비 4.5:1 이상 (WCAG AA).
- 터치 버튼 최소 44~48px.
- 모든 이미지에 대체 텍스트(`alt`), 장식용 이미지는 빈 `alt`. 헤더 로고의 `alt` 는 "대한예수교장로회 고신교회 홈".
- 키보드만으로 메뉴·검색·폼·공유 버튼 사용 가능, 포커스 표시는 골드 외곽선.
- "본문 바로가기" 링크 제공, 메뉴 열림 상태는 `aria-expanded`, 공유 결과 문구는 `aria-live` 로 전달.
- 움직임을 줄이는 설정(`prefers-reduced-motion`)을 존중합니다.
- 디자인 가이드를 바꿀 때 색 대비를 반드시 다시 확인하세요.
