# 고신교회 홈페이지

부산 사상구 주례동 고신교회 홈페이지입니다. **서버나 프로그램 설치 없이** GitHub Pages로 공개하고, GitHub 웹 화면에서 파일을 고쳐서 운영합니다.

- 기술: 순수 HTML / CSS / JavaScript (빌드 과정 없음)
- 자료(설교·소식·시간표 등)는 `data` 폴더의 파일에서 관리하고, 화면은 그 자료를 읽어 자동으로 만들어집니다.
- 처음 보는 분을 위한 요약: **글을 올릴 때는 `data` 폴더의 파일 한두 개만 고치면 됩니다.**

---

## 1. 폴더 구조

```
index.html              메인 페이지
about/                  교회소개 (인사말, 비전·표어, 연혁, 섬기는 분들, 시설안내, 오시는 길)
worship/                예배·말씀 (예배안내, 설교, 3분 묵상, 수요성경공부. 찬양대 페이지는 '다음세대·모임' 메뉴에서 연결)
books/                  담임목사 저서 (목록, 상세)
next-generation/        다음세대·모임 (부서 목록, 부서 상세)
mission/                선교 (선교 비전, 선교지, 후원 안내)
news/                   교회소식 (공지, 주보, 행사, 앨범)
newcomer/  contact/     새가족 안내, 문의
data/                   ★ 운영자가 고치는 자료 파일 (아래 설명)
assets/css/             디자인 (tokens.css 에 색상·글꼴 변수)
assets/js/site.js       화면을 그리는 공통 스크립트 (평소에는 고치지 않습니다)
assets/img/             로고, 대표 사진, 도서 표지, 앨범 사진
assets/bulletins/       주보 PDF
docs/                   디자인 가이드, 입력 필요 항목 체크리스트
tools/serve.ps1         (선택) Windows 로컬 미리보기 서버
```

`data` 폴더의 파일과 역할:

| 파일 | 들어 있는 자료 |
|---|---|
| `church.js` | 교회 이름·주소·전화, 표어, 상단 메뉴, **샘플 표시 스위치**, 문의 폼 주소 |
| `worship.js` | 예배·모임 시간표 (메인·예배안내·부서·FAQ에 자동 반영) |
| `sermons.js` | 주일 설교, 3분 묵상, 수요성경공부 |
| `news.js` | 공지사항, 주보, 행사, 교회앨범 |
| `missions.js` | 네팔·필리핀 선교 소개와 선교보고, 후원 안내 |
| `books.js` | 담임목사 저서 |
| `departments.js` | 다음세대·모임(부서) 목록 |
| `about.js` | 섬기는 분들, 연혁, 시설, FAQ, 새가족 3단계 |

## 2. 자주 하는 작업 (GitHub 웹 화면에서)

> **고치는 방법 (공통)**: GitHub에서 저장소를 열고 → 파일을 클릭 → 오른쪽 위 **연필 아이콘(Edit)** → 내용 수정 → **Commit changes** 버튼. 1~2분 뒤 사이트에 반영됩니다.
>
> **주의**: 따옴표(`'`)와 쉼표(`,`)를 지우지 마세요. 항목 하나는 `{ ... },` 한 덩어리입니다. 쉼표가 빠지면 그 파일의 내용이 모두 안 보일 수 있습니다. 잘못 고쳤다면 6번의 "되돌리기"를 보세요.

### (1) 설교 추가 — `data/sermons.js`
`KOSIN.sermons = [` 바로 아래에 한 덩어리를 복사해서 붙여넣고 내용만 바꿉니다. 최신 날짜가 자동으로 맨 위에 나옵니다.

```js
{ id: '2026-11-22', title: '설교 제목', date: '2026-11-22', scripture: '요한복음 3:16', preacher: '김경헌 담임목사', youtube: 'AbCdEfGhIjK', summary: '한두 문장 요약' },
```

- `youtube`: 유튜브 주소가 `https://www.youtube.com/watch?v=AbCdEfGhIjK` 이면 `v=` 뒤의 `AbCdEfGhIjK` 만 넣습니다. 비워 두면 "영상 준비 중"으로 나옵니다.
- 메인 "이번 주 말씀"에는 가장 최근 날짜의 설교가 나옵니다.
- 3분 묵상(`meditations`), 수요성경공부(`wednesday`)도 같은 방식입니다.

### (2) 공지·교회소식 추가 — `data/news.js`
`KOSIN.notices = [` 아래에 추가합니다.

```js
{ id: 'n-2026-11-22', title: '공지 제목', date: '2026-11-22', category: '공지', body: '내용입니다.<br>줄을 바꾸려면 br 을 씁니다.' },
```

- 상단에 고정하려면 `pinned: true,` 를 넣습니다.
- 눌러서 펼쳐지는 글 내용은 `body`, 다른 곳으로 연결하려면 `link: 'https://...'` 를 씁니다.

### (3) 주보 올리기
1. GitHub에서 `assets/bulletins` 폴더로 들어가 **Add file → Upload files** 로 PDF를 올립니다. 파일 이름은 `2026-11-22.pdf` 처럼 날짜로 하세요.
2. `data/news.js` 의 `KOSIN.bulletins = [` 아래에 한 줄을 추가합니다.
```js
{ id: 'b-2026-11-22', title: '2026년 11월 22일 주보', date: '2026-11-22', file: 'assets/bulletins/2026-11-22.pdf' },
```
메인의 "이번 주 주보" 버튼에는 가장 최근 날짜의 주보가 걸립니다.

### (4) 예배 시간 수정 — `data/worship.js`
`time`(시간), `place`(장소)만 고칩니다. 메인, 예배안내, 부서 페이지, FAQ, 새가족 안내에 모두 자동 반영됩니다. 메인의 큰 카드 3개는 `featured: true` 인 항목입니다.

### (5) 담임목사 저서 추가 — `data/books.js`
1. 표지 이미지를 `assets/img/books` 폴더에 올립니다.
2. 샘플 두 덩어리(`sample-1`, `sample-2`)를 지우고, 실제 책 정보를 한 덩어리씩 입력합니다. 항목 설명은 파일 맨 위 주석에 있습니다.
3. 책 하나마다 상세 페이지가 자동으로 만들어집니다. (`books/detail.html?id=책id`)

### (6) 교회 앨범 — 행사 사진·영상 올리기 (`교회 앨범 > 교회 행사 / 선교 행사`)
1. 사진을 가로·세로 **긴 변 1280px, 한 장 200KB 안팎**으로 줄여 `assets/img/events` 폴더에 올립니다. 파일 이름은 `행사id_001.jpg`, `행사id_002.jpg` … (3자리 번호)
2. `data/news.js` 의 `KOSIN.events` 에 행사 한 줄을 추가합니다. 사진은 **장 수만** 적으면 됩니다.
```js
{ id: 'e-2026-11-22', title: '행사 이름', date: '2026-11-22', category: '교회행사', photos: 12, videos: ['유튜브영상ID'] },
```
   - `category` : `'교회행사'` → 교회 행사, `'선교행사'` → 선교 행사 (선교 행사에는 카카오톡 공유 버튼도 붙습니다)
   - `videos` : 유튜브는 영상 ID(주소 끝의 11자리), 짧은 영상 파일(mp4, 25MB 이하)은 `assets/img/events` 에 올리고 파일 이름을 적습니다. 긴 영상은 유튜브에 올리고 ID 만 적는 것을 권합니다.
3. 메인 화면의 "교회 앨범"에는 사진이 있는 최신 행사의 첫 사진이 자동으로 나옵니다.
어린이·청소년 사진은 보호자 동의를 받은 뒤에 올리세요.

### (6-1) 주보·설교 영상
- 주보: 매주 PDF 를 `assets/bulletins/2026-11-29.pdf` 처럼 올리고 `data/news.js` 의 `bulletins` 맨 위에 한 줄을 추가하면, 메인의 "이번 주 주보"에서 쪽마다 좌우로 넘겨 볼 수 있습니다.
- 설교·3분 묵상·수요성경공부·쇼츠: `data/sermons.js` 에 줄을 추가합니다 (유튜브 영상 ID 만 넣으면 썸네일이 자동으로 나옵니다).

### (7) 대표 사진·로고·섬기는 분 사진
- 메인 맨 위 큰 사진: `assets/img/hero.jpg` 로 올립니다 (가로 1920px 이상, 400KB 이하 권장). 파일이 없으면 파란 배경이 나옵니다.
- 로고: 교회 로고(`assets/img/logo.png`, 가로형 투명 배경 PNG)가 들어 있습니다. 더 선명한 원본(SVG 또는 큰 PNG)이 생기면 같은 이름으로 덮어쓰거나 `data/church.js` 의 `logo:` 경로를 바꾸세요. 브라우저 탭 아이콘(`favicon.png`)과 카톡 공유 미리보기 이미지(`og-image.png`)도 같은 방식으로 교체할 수 있습니다.
- 사이트 색상: 교회 로고의 버건디가 기본색입니다. 색을 바꾸려면 `assets/css/tokens.css` 의 값을 고칩니다. (자세한 내용은 `docs/DESIGN-GUIDE.md`)
- 사진 경로 입력 예: `data/about.js` 의 `photo: 'assets/img/people/kim.jpg'`

### (8) 교회 이메일·유튜브·문의 폼 — `data/church.js`
`email`, `youtube`, `formEndpoint` 를 채웁니다. 비워 두면 화면에 표시되지 않습니다.

## 3. 미리보기 (내 컴퓨터에서)

- **가장 쉬운 방법**: 폴더의 `index.html` 을 더블클릭하면 브라우저에서 열립니다. (인터넷이 연결되어 있어야 글꼴과 지도가 보입니다.)
- Windows에서 서버처럼 확인하려면: 폴더에서 PowerShell을 열고 아래를 실행한 뒤 `http://localhost:8080/` 으로 접속합니다.
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\serve.ps1 -Port 8080
```

## 4. GitHub Pages로 공개하기

1. 교회 공용 GitHub 계정(또는 Organization)을 만들고, 새 저장소(Repository)를 만듭니다. 무료 Pages는 보통 **공개 저장소**를 사용하므로, 저장소 안의 파일은 누구나 볼 수 있습니다. 개인정보(성도 연락처 등)와 후원 계좌는 승인 없이 올리지 마세요.
2. 이 폴더의 **모든 파일과 폴더**를 저장소에 올립니다. (`.nojekyll` 파일도 함께. 웹에서 올릴 때 숨김 파일이 빠지면 저장소에서 **Add file → Create new file** 로 `.nojekyll` 이라는 빈 파일을 만드세요.)
3. 저장소의 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**.
4. 1~2분 뒤 `https://계정이름.github.io/저장소이름/` 같은 주소가 나옵니다. 먼저 이 주소로 교회 관계자에게 보여 주고 확인을 받으세요. (모든 링크가 상대 경로라서 이 주소에서도 정상 동작합니다.)
5. `404.html` 은 직접 연결한 도메인(또는 `계정이름.github.io`)에서만 정상적으로 꾸며져 보입니다. 임시 주소에서는 단순한 화면으로 보일 수 있습니다.

### 도메인(www.kosinchurch.com) 연결 — 가장 마지막에
> 이 사이트에는 기존 홈페이지 주소와 같은 **`https://www.kosinchurch.com`** 이 미리 들어 있습니다. (공유 미리보기 이미지, `sitemap.xml`, `robots.txt`) 다른 주소로 바꾸고 싶으면 아래 "도메인 주소를 나중에 바꾸고 싶을 때"를 보세요.

- **새 사이트 확인이 모두 끝난 뒤에** 진행하세요. DNS를 바꾸는 순간부터 기존 아임웹 사이트는 열리지 않습니다.
- 먼저 도메인을 어디서 구입했는지(아임웹 / 가비아 / 후이즈 등) 확인하세요. 아임웹에서 구입한 도메인이면 아임웹 도메인 설정에서 DNS를 바꿀 수 있는지 확인이 필요합니다.
- GitHub **Settings → Pages → Custom domain** 에 `www.kosinchurch.com` 을 입력하고 저장한 뒤, 도메인 등록처의 DNS 설정에서 GitHub가 안내하는 값으로 바꿉니다. 보통 `www` 는 CNAME(`계정이름.github.io`)으로, 주소 앞에 www가 없는 `kosinchurch.com` 은 A 레코드(GitHub가 안내하는 IP 주소들)로 설정하며, 둘 다 설정하면 www 없이 들어온 방문자도 www 주소로 보내집니다. 정확한 값은 GitHub 공식 문서(*Managing a custom domain for your GitHub Pages site*)에서 최신 내용을 확인하세요.
- 연결 후 **Enforce HTTPS** 를 체크합니다.
- 이메일 등 다른 서비스가 같은 도메인을 쓰고 있다면 **MX, TXT 레코드는 지우지 마세요.**
- 연결 후에는 `robots.txt`, `sitemap.xml`, 각 페이지의 공유 미리보기 이미지 주소가 실제 도메인과 같은지 확인하세요.
- 새 사이트가 며칠간 문제없이 돌아가는 것을 확인한 뒤에 아임웹 해지를 결정하세요.

### 도메인 주소를 나중에 바꾸고 싶을 때
도메인은 **언제든 바꿀 수 있습니다.** 페이지의 모든 링크가 상대 경로라서, 사이트는 어떤 주소에서도 그대로 동작합니다. 주소가 직접 적혀 있는 곳은 아래 세 군데뿐이고, 카카오톡 공유 버튼이 보내는 링크는 방문자가 보고 있던 실제 주소를 그대로 씁니다.

| 주소가 적힌 곳 | 하는 일 |
|---|---|
| 각 페이지 `<head>` 의 `og:image` (26개 페이지) | 카카오톡 등에서 링크 미리보기 이미지 |
| `sitemap.xml` (23개 주소) | 검색엔진에 알려 주는 페이지 목록 |
| `robots.txt` | 사이트맵 위치 안내 |

**한 번에 바꾸는 방법 (Windows PowerShell)** — 폴더를 연 상태에서 아래처럼 실행합니다. 바꾸기 전에 `-DryRun` 을 붙여서 어디가 바뀔지 먼저 볼 수 있습니다.
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools\set-domain.ps1 -Domain https://새도메인.com -DryRun
powershell -NoProfile -ExecutionPolicy Bypass -File tools\set-domain.ps1 -Domain https://새도메인.com
```
- 주소는 `https://` 로 시작하고 뒤에 경로를 붙이지 않습니다. (예: `https://www.kosinchurch.com`)
- 같은 주소로 다시 실행하면 "이미 설정됨"이라고만 나오고, 다른 주소로 바꿨다가 되돌려도 파일 내용은 그대로입니다.
- 이 PC가 아닌 곳에서 GitHub 웹 화면만 쓰는 경우에는 파일을 하나씩 고쳐야 하니, 담당자 PC에서 한 번 실행한 뒤 바뀐 파일을 GitHub에 올리는 방법이 편합니다.

**도메인을 바꿀 때 함께 확인할 것**
1. GitHub Settings → Pages → Custom domain 을 새 주소로 바꾸고, 도메인 등록처의 DNS도 새 주소에 맞게 변경
2. 카카오 디벨로퍼스에 등록한 사이트 도메인을 새 주소로 추가 (카카오톡 공유 카드를 쓰는 경우)
3. 구글 서치콘솔·네이버 서치어드바이저 등에 등록했다면 새 주소로 다시 등록
4. 이전 주소로 들어오는 방문자가 많다면, 이전 주소에서 새 주소로 자동 이동(리다이렉트)되게 설정

## 5. 문의 폼 연결 (Formspree 예시)

GitHub Pages에는 서버가 없어서 문의 폼은 외부 접수 서비스를 이용합니다.

1. [Formspree](https://formspree.io) 에 교회 이메일로 가입하고 새 폼을 만듭니다. (무료 요금제는 월 접수 건수 제한이 있으니 요금제를 확인하세요.)
2. 폼 주소(`https://formspree.io/f/xxxxxxxx`)를 복사해서 `data/church.js` 의 `formEndpoint: ''` 안에 붙여넣습니다.
3. 사이트에서 테스트 문의를 보내 이메일이 오는지 확인합니다.
4. 문의 내용이 외부 서비스를 거치므로, `privacy.html`(개인정보처리방침)의 "처리 위탁" 항목에 사용하는 서비스를 적어 주세요.

연결 전에는 폼을 보내면 "접수 기능이 아직 연결되지 않았습니다. 전화로 문의해 주세요" 안내가 나옵니다.

## 5-2. 공유하기(카카오톡) 설정

선교 페이지(선교 비전, 네팔·필리핀, 후원 안내) 아래에 **카카오톡으로 공유 / 링크 복사 / 다른 앱으로 공유** 버튼이 있습니다. 눌렀을 때 **지금 보고 있는 페이지의 주소**가 공유됩니다. (예: 네팔 선교 페이지에서 누르면 네팔 선교 페이지 주소)

- **따로 설정하지 않아도 동작합니다.**
  - 휴대폰: 공유 창이 열리고 거기서 카카오톡을 고를 수 있습니다. (https 주소에서만 동작하며, GitHub Pages는 기본으로 https입니다.)
  - 공유 창이 없는 컴퓨터: 링크가 복사되고 "카카오톡 대화창에 붙여넣어 보내세요"라고 안내합니다.
- **제목과 이미지가 붙은 카카오톡 공유 카드를 쓰려면** (선택):
  1. 카카오 디벨로퍼스(developers.kakao.com)에서 앱을 만들고, 앱 설정의 플랫폼에 사이트 도메인(예: `https://www.kosinchurch.com`)을 등록합니다. 등록하지 않은 도메인에서는 카카오가 공유를 막습니다.
  2. 앱의 **JavaScript 키**를 `data/church.js` 의 `kakaoJsKey: ''` 안에 붙여넣습니다.
  3. 카카오 SDK 주소의 버전은 `assets/js/site.js` 의 `loadKakao` 안에 있습니다. 카카오 문서에서 최신 안정 버전을 확인해 바꿀 수 있습니다. (SDK를 불러오지 못하면 자동으로 위의 기본 동작으로 넘어갑니다.)
- **링크를 카톡 대화방에 붙여넣었을 때 보이는 미리보기**(제목, 설명, 이미지)는 각 페이지 `<head>` 의 `og:` 정보로 만들어집니다. 이미지는 `assets/img/og-image.png` 이고 주소는 `https://www.kosinchurch.com/assets/img/og-image.png` 로 적혀 있어서, **도메인을 연결한 뒤부터** 이미지가 나옵니다. 카카오는 한 번 읽은 미리보기를 저장해 두므로, 나중에 바꾸면 카카오 개발자 사이트의 '공유 디버거' 도구로 새로 읽혀야 할 수 있습니다.
- **선교 내용 하나하나에도 "카카오톡 공유" 버튼이 있습니다.** (페이지 전체 공유와 별개)
  - 선교보고 한 건마다, 선교 행사(`category: '선교행사'`) 한 건마다, 메인과 선교 첫 페이지의 선교지 카드마다 버튼이 붙습니다. 교회 행사(`교회행사`)에는 붙지 않습니다.
  - 버튼을 누르면 **그 항목만 가리키는 주소**(예: `.../mission/field.html?id=philippines#r-2026-11-17-hdni19`)가 공유됩니다. 받은 사람이 링크를 열면 그 항목으로 바로 이동해서 강조(베이지 배경 + 금색 선)됩니다.
  - 항목 주소의 `#r-...` 부분은 **날짜와 제목으로 자동으로 만들어집니다.** 새 선교보고를 맨 위에 추가해도 이미 공유한 주소는 바뀌지 않습니다. 단, **날짜나 제목을 고치면 주소가 달라져서** 예전에 공유한 링크는 그 항목을 못 찾고 페이지 맨 위만 열립니다. 고쳐도 주소를 유지하고 싶으면 항목에 `id: 'philippines-2026-11'` 처럼 직접 적어 두세요.
  - 카카오톡으로 보낼 때 제목은 "필리핀 선교 · 마닐라 선교센터 공사 진행 상황 | 고신교회", 설명은 "필리핀 선교보고 · 2026.11.17" 형태입니다.
- 다른 페이지에도 공유 버튼을 넣으려면 원하는 위치에 `<div data-render="share"></div>` 한 줄을 추가하세요.

## 6. 공개 전 점검 / 되돌리기

### 공개 전 점검 체크리스트
- [ ] `docs/CHECKLIST.md` 의 `[입력 필요]` 항목을 모두 채웠다
- [ ] `data/church.js` 의 `showSamples` 를 **`false`** 로 바꿨다 (화면의 "샘플" 표시와 임시 자료가 모두 사라집니다)
- [ ] `data/books.js` 의 샘플 두 권을 지우고 실제 저서 정보를 넣었다 (저서가 없으면 메인의 저서 구역은 자동으로 숨겨집니다)
- [ ] 휴대폰과 PC에서 모든 메뉴와 링크를 눌러 봤다
- [ ] 예배 시간과 층 표기를 교회에서 확인받았다
- [ ] 담임목사님과 담당 교역자의 승인을 받았다
- [ ] 사진 게시 동의(특히 어린이·청소년), 저서 표지 사용 허락을 확인했다

### 잘못 고쳤을 때 되돌리기
1. 고친 파일을 열고 오른쪽 위 **History** 를 누릅니다.
2. 문제가 없던 때의 기록을 눌러 그 시점의 파일 내용을 엽니다. (`<>` 버튼 또는 **View file**)
3. 내용을 전체 복사해서 현재 파일의 편집 화면에 붙여넣고 다시 **Commit changes** 합니다.

### 사이트에 아무것도 안 보일 때
- 거의 항상 `data` 폴더 파일의 쉼표나 따옴표가 빠진 경우입니다. 방금 고친 파일을 위의 방법으로 되돌려 보세요.
- 브라우저에서 `Ctrl + F5` 로 새로고침하세요. 방금 올린 내용이 바로 안 보이면 1~2분 기다린 뒤 다시 확인하세요.
